# M12 Fleet Health Grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship M12 fleet health grid (no saved checks) with multi-value tags, progressive pooled refresh, read-only gate, and visible stale cache.

**Architecture:** Domain fleet models + `FleetHealthProbe` (read) + `assertFleetReadOnly` / `ProbeScope.fleet` gate; reuse `runPooled`; Drift schema 9 for `host_tags` + `fleet_cache`; presentation `FleetScreen` composes design system only.

**Tech Stack:** Flutter/Dart, Drift, existing SSH session pool / `runHostProbe`, `pooled_run.dart`.

## Global Constraints

- Compose from `lib/design/` only.
- Concurrency cap 5; per-host timeout 10s.
- Only `RiskLevel.read` in fleet mode (property test).
- Tags multi-value; UI filter one tag at a time.
- Cache last-known with visible age; offline shows marked cache.
- Saved fleet checks deferred.
- Migrasi Drift stepwise `from < n`.
